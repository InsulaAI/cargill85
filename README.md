# Elefante 85 anos · Filme Hero

Tratamento com a visão de direção de Harbor (Fabio Hacker & Luciano Mathias). Página única
(`index.html`), sem build, publicada pelo GitHub Pages a partir do branch `main` (raiz).

- `img/q-*.webp` — quadros gerados para o filme (com grão e desfoque leve, para tirar o aspecto "sharp")
- Nenhuma imagem do deck da agência é usada na página; cada quadro aparece uma vez só
- `img/insula.webp` — logo Insula AI (símbolo + nome lado a lado), montado das partes do logo oficial "SEM BG" do Drive
- `img/elefante-logo.svg` — logo Elefante vetorizado da cartela do deck (a página usa uma cópia embutida)
- `video/` — as quatro referências de movimento, em MP4 (H.264) e WebM (VP9), com capa `.webp`
- `producao/` — prompts de imagem para o Magnific (não aparece na página)

Para publicar: commit e push no `main`. O branch `gh-pages` não é mais usado.
